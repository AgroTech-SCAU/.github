# AgroTech-SCAU `.github`

AgroTech-SCAU Organization 的公开门户与公共治理仓库

## 当前结构

```text
.github/
├── README.md
└── profile/
    └── README.md
```

`profile/README.md` 用于 Organization 公共首页

`README.md` 用于说明本仓库职责

## 边界

`.github` 只维护适合公开的信息

项目负责人、成员安排、项目进度、内部里程碑、内部会议记录与其他协会隐私信息统一放在 `.github-private`

本仓库不存放具体机器人实现代码
