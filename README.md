# AgroTech-SCAU `.github`

AgroTech-SCAU Organization 的公开门户与公共治理仓库

## 当前结构

```text
.github/
├── README.md
└── profile/
    └── README.md
```

`profile/README.md` 用于 Organization 公共首页

`README.md` 用于说明本仓库职责

## 边界

`.github` 只维护适合公开的信息

项目负责人、协作者、当前版本、下一步目标和人员需求以飞书第五届《项目安排》为准；历史各届记录保留在飞书，不作为当前安排

`.github-private` 用于成员登记、GitHub 账号映射、Team / Repository 权限申请与内部协作规则

具体代码、Issue、PR、Release 和技术规划维护在各项目仓库；公共首页仅提供公开项目与技术资产入口

## 导航维护

- 项目编号与名称对应第五届《项目安排》，同一项目的子项使用 `1.1`、`1.2` 等编号
- 尚未同步到公开导航的项目可以保留编号空缺，不为填补空缺重排其他编号
- 仓库名称和链接以 GitHub 实际仓库为准，个人仓库单独注明
- 比赛项目、已归档仓库、公共资产和工程规范分别组织，不用仓库归档状态推断其他项目的实际进度
- 项目版本与技术进度由负责人维护，不在公共首页重复记录

本仓库不存放具体机器人实现代码
